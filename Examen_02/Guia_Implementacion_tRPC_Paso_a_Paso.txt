PASO 08 - IMPLEMENTAR EL REPOSITORIO DE DATOS EN MEMORIA
====================================================================================================
Crear src/repositories/memoria.ts (ANEXO F).
La clase RepositorioMemoria utiliza structuredClone() de los datos iniciales.
Los cambios realizados al insertar, actualizar o eliminar solo viven en memoria;
al reiniciar el servidor, los arreglos originales se recuperan desde el JSON.

Métodos principales:
  productos()      retorna arreglo clonado
  productoPorId()  busca un ProductID
  insertar()       comprueba ID duplicado y añade producto
  modificar()      actualiza campos permitidos
  eliminar()       extrae el producto de la lista

Los métodos son async para compartir contrato con la implementación MongoDB.

PASO 11 - IMPLEMENTAR JWT Y CONTRASEÑAS CON HASH
====================================================================================================
Crear src/server/auth.ts (ANEXO J).
Se usan jsonwebtoken y bcryptjs:

1. autenticar(email, password) comprueba correo y hash bcrypt.
2. Si las credenciales son correctas, se firma un JWT de una hora.
3. usuarioDesdeToken() analiza el encabezado Authorization: Bearer <token>.
4. jwt.verify valida firma, algoritmo HS256, issuer y usuario del laboratorio.
5. Si el token falta o no es válido, el usuario del contexto queda null.

Esta demostración utiliza UNA identidad local con rol admin; no administra un padrón
de usuarios en MongoDB ni implementa permisos de varios roles.

PASO 13 - INICIALIZAR EL ROUTER Y VALIDAR ENTRADAS CON ZOD
====================================================================================================
Crear src/server/router.ts (ANEXO L).

Primero inicializar tRPC usando el tipo Contexto:

    const t = initTRPC.context<Contexto>().create();
    const publico = t.procedure;

Crear middleware protegido para operaciones de escritura:

    const protegido = t.procedure.use(({ ctx, next }) => {
      if (!ctx.usuario) throw new TRPCError({ code: "UNAUTHORIZED", ... });
      return next({ ctx: { usuario: ctx.usuario } });
    });

Definir esquemas Zod: ID entero positivo, nombres requeridos, precios >= 0,
stock >= 0, campos permitidos para seleccionar y ordenar, etc.

Diferencia con GraphQL: no se escribe un esquema typeDefs en SDL ni resolvers
Apollo. Los routers definen los procedimientos y el cliente infiere sus tipos.

PASO 18 - IMPLEMENTAR CRUD PROTEGIDO (E + G)
====================================================================================================
En el router definir tres mutaciones protegidas por JWT:

    productos.crear
    productos.actualizar
    productos.eliminar

Antes de insertar, comprobar que CategoryID y SupplierID existan.
Validar campos con Zod y rechazar ID duplicado con CONFLICT.
Al actualizar, comprobar existencia y permitir cambios parciales sin modificar ProductID.
Al eliminar, comprobar existencia, devolver el registro eliminado y verificar
luego la búsqueda por ID: debe retornar null.

El cliente realiza estas acciones sobre un ID de prueba generado dinámicamente,
y elimina su producto al terminar; no borra los datos base de Northwind.
La autorización se comprueba antes de mutar: sin JWT se espera UNAUTHORIZED.

2. 'tsx' o 'tsc' no se reconoce:
   npm install no concluyó. Corregir primero la instalación; no instalar globalmente.
3. Cannot find name process o node:process:
   comprobar @types/node y tsconfig.json "types": ["node"]; luego npm run check.
4. EADDRINUSE 127.0.0.1:4317:
   hay otra aplicación escuchando; cerrar la instancia propia antes de reiniciar.
5. ECONNREFUSED 127.0.0.1:4317:
   iniciar el servidor en una terminal antes de ejecutar el cliente.
6. No procedure found on path "":
   la raíz / no tiene procedimiento. Usar /productos.todos o el cliente.
7. "new" de Mongoose está deprecado:
   es advertencia no bloqueante; planificar cambio a returnDocument: "after".
8. Nombres acentuados como "C├┤te":
   revisar la codificación UTF-8 en terminal o archivo; MongoDB devolvió
   correctamente "Côte de Blaye" y "Thüringer Rostbratwurst".
9. PowerShell NativeCommandError al usar *>&1 con npm:
   npm escribe avisos en stderr; para capturar la salida estándar usar
   npm run test:trpc | Tee-Object -FilePath .\capturas\pruebas-trpc.txt.
10. Error al cambiar DB_MODE mientras el servidor sigue vivo:
    cerrar servidor con Ctrl + C y volver a iniciarlo para leer el .env actualizado.

====================================================================================================
PASO 30 - CONCLUSIONES PARA LA PRUEBA PARCIAL
====================================================================================================
Se construyó una API tRPC con TypeScript y Node.js que trabaja con el dataset
Northwind de la práctica previa de GraphQL. La capa de comunicación tRPC usa
procedimientos tipados validados con Zod. El mismo router sirve los datos desde
arreglos en memoria o colecciones MongoDB, seleccionados por DB_MODE.

Se probaron consultas totales, selección de campos, filtros, relaciones lógicas,
agregaciones en Node.js, CRUD de productos, paginación/ordenamiento y autenticación
mediante JWT. Las pruebas A-G terminaron correctamente en memoria y en MongoDB.

Comparación resumida para el docente:
  REST     : API de recursos y métodos HTTP.
  GraphQL  : API de consultas y mutaciones descrita por un esquema GraphQL.
  gRPC     : servicios RPC con contratos Protocol Buffers (parte del compañero).
  tRPC     : procedimientos RPC y tipos inferidos entre cliente/servidor TypeScript.

Ni gRPC ni tRPC dependen exclusivamente de MongoDB. La base de datos es una
decisión de la implementación del backend. En este proyecto se demostraron
dos modos: memoria y MongoDB.

LIMITACIONES DECLARADAS: autenticación solo con un usuario de laboratorio;
no hay control multirol completo ni consultas optimizadas por índices, agregación
MongoDB o $lookup a nivel de motor. Son simplificaciones explícitas de esta demo.

import { datosIniciales } from "../data.js";
import type { Categoria, Proveedor, Producto, NuevoProducto, CambioProducto, Repositorio } from "../types.js";

export class RepositorioMemoria implements Repositorio {
  private readonly listaCategorias: Categoria[];
  private readonly listaProveedores: Proveedor[];
  private readonly listaProductos: Producto[];

  constructor() {
    // No se modifica el JSON original; los cambios se pierden al reiniciar.
    this.listaCategorias = structuredClone(datosIniciales.categories);
    this.listaProveedores = structuredClone(datosIniciales.suppliers);
    this.listaProductos = structuredClone(datosIniciales.products);
  }

  async categorias(): Promise<Categoria[]> { return structuredClone(this.listaCategorias); }
  async proveedores(): Promise<Proveedor[]> { return structuredClone(this.listaProveedores); }
  async productos(): Promise<Producto[]> { return structuredClone(this.listaProductos); }

  async productoPorId(id: number): Promise<Producto | null> {
    const encontrado = this.listaProductos.find((p) => p.ProductID === id);
    return encontrado ? structuredClone(encontrado) : null;
  }

  async insertar(producto: NuevoProducto): Promise<Producto> {
    if (this.listaProductos.some((p) => p.ProductID === producto.ProductID)) {
      throw new Error("PRODUCTO_DUPLICADO");
    }
    this.listaProductos.push(structuredClone(producto));
    return structuredClone(producto);
  }

  async modificar(id: number, cambios: CambioProducto): Promise<Producto | null> {
    const i = this.listaProductos.findIndex((p) => p.ProductID === id);
    if (i === -1) return null;
    this.listaProductos[i] = { ...this.listaProductos[i], ...structuredClone(cambios) };
    return structuredClone(this.listaProductos[i]);
  }

  async eliminar(id: number): Promise<Producto | null> {
    const i = this.listaProductos.findIndex((p) => p.ProductID === id);
    if (i === -1) return null;
    const [eliminado] = this.listaProductos.splice(i, 1);
    return structuredClone(eliminado);
  }
}

import mongoose, { Schema } from "mongoose";
import type { Categoria, Proveedor, Producto, NuevoProducto, CambioProducto, Repositorio } from "../types.js";
import { datosIniciales } from "../data.js";

// Colecciones dedicadas al examen; se exige conexión real cuando DB_MODE=mongo.
const categoriaSchema = new Schema({
  CategoryID: { type: Number, required: true, unique: true },
  CategoryName: { type: String, required: true },
  Description: { type: String, required: true }
}, { collection: "categories", versionKey: false });

const proveedorSchema = new Schema({
  SupplierID: { type: Number, required: true, unique: true },
  CompanyName: { type: String, required: true },
  ContactName: { type: String, required: true },
  ContactTitle: { type: String, required: true },
  Country: { type: String, required: true },
  City: { type: String, required: true },
  Address: { type: String, required: true }
}, { collection: "suppliers", versionKey: false });

const productoSchema = new Schema({
  ProductID: { type: Number, required: true, unique: true },
  ProductName: { type: String, required: true },
  SupplierID: { type: Number, required: true },
  CategoryID: { type: Number, required: true },
  QuantityPerUnit: { type: String, required: true },
  UnitPrice: { type: Number, required: true, min: 0 },
  UnitsInStock: { type: Number, required: true, min: 0 },
  ReorderLevel: { type: Number, required: true, min: 0 }
}, { collection: "products", versionKey: false });

const CategoriaModel = mongoose.model("ExamenCategoria", categoriaSchema);
const ProveedorModel = mongoose.model("ExamenProveedor", proveedorSchema);
const ProductoModel = mongoose.model("ExamenProducto", productoSchema);

function sinMongo<T>(doc: Record<string, unknown> | null): T | null {
  if (!doc) return null;
  const { _id, __v, ...campos } = doc;
  return campos as T;
}

export class RepositorioMongo implements Repositorio {
  async categorias(): Promise<Categoria[]> {
    return (await CategoriaModel.find().sort({ CategoryID: 1 }).lean())
      .map((d) => sinMongo<Categoria>(d as Record<string, unknown>)!);
  }
  async proveedores(): Promise<Proveedor[]> {
    return (await ProveedorModel.find().sort({ SupplierID: 1 }).lean())
      .map((d) => sinMongo<Proveedor>(d as Record<string, unknown>)!);
  }
  async productos(): Promise<Producto[]> {
    return (await ProductoModel.find().sort({ ProductID: 1 }).lean())
      .map((d) => sinMongo<Producto>(d as Record<string, unknown>)!);
  }
  async productoPorId(id: number): Promise<Producto | null> {
    const doc = await ProductoModel.findOne({ ProductID: id }).lean();
    return sinMongo<Producto>(doc as Record<string, unknown> | null);
  }
  async insertar(producto: NuevoProducto): Promise<Producto> {
    const creado = await ProductoModel.create(producto);
    return sinMongo<Producto>(creado.toObject() as Record<string, unknown>)!;
  }
  async modificar(id: number, cambios: CambioProducto): Promise<Producto | null> {
    const doc = await ProductoModel.findOneAndUpdate(
      { ProductID: id }, { $set: cambios }, { new: true, runValidators: true }
    ).lean();
    return sinMongo<Producto>(doc as Record<string, unknown> | null);
  }
  async eliminar(id: number): Promise<Producto | null> {
    const doc = await ProductoModel.findOneAndDelete({ ProductID: id }).lean();
    return sinMongo<Producto>(doc as Record<string, unknown> | null);
  }
}

export async function conectarMongo(): Promise<void> {
  const uri = process.env.MONGO_URI;
  if (!uri) throw new Error("Falta MONGO_URI en .env");
  await mongoose.connect(uri, { serverSelectionTimeoutMS: 5000 });
}

// No borra ni sobrescribe documentos existentes. Se usa sólo en la base del examen.

  })));
  await ProductoModel.bulkWrite(datosIniciales.products.map((dato) => ({
    updateOne: { filter: { ProductID: dato.ProductID }, update: { $setOnInsert: dato }, upsert: true }
  })));
}

import bcrypt from "bcryptjs";
import jwt, { type JwtPayload } from "jsonwebtoken";

export interface Usuario { email: string; rol: "admin"; }

function secreto(): string {
  const valor = process.env.JWT_SECRET;
  if (!valor || valor.length < 32) {
    throw new Error("JWT_SECRET no configurado. Ejecuta npm run setup.");
  }
  return valor;
}

export async function autenticar(email: string, password: string): Promise<{ token: string; usuario: Usuario } | null> {
  const correo = process.env.DEMO_EMAIL;
  const hash = process.env.DEMO_PASSWORD_HASH;
  if (!correo || !hash) throw new Error("Usuario de demostración no configurado. Ejecuta npm run setup.");
  if (email !== correo || !(await bcrypt.compare(password, hash))) return null;
  const usuario: Usuario = { email: correo, rol: "admin" };
  const token = jwt.sign({ rol: usuario.rol }, secreto(), {
    algorithm: "HS256", subject: usuario.email, expiresIn: "1h", issuer: "examen02-trpc"
  });
  return { token, usuario };
}

export function usuarioDesdeToken(authorization: string | undefined): Usuario | null {
  if (!authorization?.startsWith("Bearer ")) return null;
  try {
    const datos = jwt.verify(authorization.substring(7), secreto(), {
      algorithms: ["HS256"], issuer: "examen02-trpc"
    }) as JwtPayload;
    if (typeof datos.sub !== "string" || datos.sub !== process.env.DEMO_EMAIL || datos.rol !== "admin") return null;
    return { email: datos.sub, rol: "admin" };
  } catch {
    return null;
  }
}

import type { CreateHTTPContextOptions } from "@trpc/server/adapters/standalone";
import type { Repositorio } from "../types.js";
import { usuarioDesdeToken, type Usuario } from "./auth.js";

export interface Contexto {
  repo: Repositorio;
  usuario: Usuario | null;
}

export function construirContexto(repo: Repositorio) {
  return ({ req }: CreateHTTPContextOptions): Contexto => ({
    repo,
    usuario: usuarioDesdeToken(req.headers.authorization)
  });
}

import { initTRPC, TRPCError } from "@trpc/server";
import { z } from "zod";
import type { Contexto } from "./context.js";
import { autenticar } from "./auth.js";
import type { Producto } from "../types.js";

const t = initTRPC.context<Contexto>().create();
const publico = t.procedure;
const protegido = t.procedure.use(({ ctx, next }) => {
  if (!ctx.usuario) throw new TRPCError({ code: "UNAUTHORIZED", message: "Se requiere JWT válido" });
  return next({ ctx: { usuario: ctx.usuario } });
});

const id = z.number().int().positive();
const campoProducto = z.enum([
  "ProductID", "ProductName", "SupplierID", "CategoryID",
  "QuantityPerUnit", "UnitPrice", "UnitsInStock", "ReorderLevel"
]);
const datosProducto = z.object({
  ProductID: id,
  ProductName: z.string().trim().min(2).max(150),
  SupplierID: id,
  CategoryID: id,
  QuantityPerUnit: z.string().trim().min(1).max(150),
  UnitPrice: z.number().nonnegative(),
  UnitsInStock: z.number().int().nonnegative(),
  ReorderLevel: z.number().int().nonnegative()
}).strict();
const cambiosProducto = datosProducto.omit({ ProductID: true }).partial().refine(
  (cambios) => Object.keys(cambios).length > 0,
  { message: "Indica al menos un campo para modificar" }
);

async function validarRelaciones(repo: Contexto["repo"], producto: Pick<Producto, "CategoryID" | "SupplierID">): Promise<void> {
  const [categorias, proveedores] = await Promise.all([repo.categorias(), repo.proveedores()]);
  if (!categorias.some((c) => c.CategoryID === producto.CategoryID)) {
    throw new TRPCError({ code: "BAD_REQUEST", message: "CategoryID no existe" });
  }
  if (!proveedores.some((p) => p.SupplierID === producto.SupplierID)) {
    throw new TRPCError({ code: "BAD_REQUEST", message: "SupplierID no existe" });
  }
}

function traducirError(error: unknown): never {
  if (error instanceof Error && (error.message === "PRODUCTO_DUPLICADO" ||
    ("code" in error && error.code === 11000))) {
    throw new TRPCError({ code: "CONFLICT", message: "ProductID ya existe" });
  }
  throw error;
}

export const appRouter = t.router({
  auth: t.router({
    login: publico.input(z.object({ email: z.email(), password: z.string().min(1) }))
      .mutation(async ({ input }) => {
        const acceso = await autenticar(input.email, input.password);
        if (!acceso) throw new TRPCError({ code: "UNAUTHORIZED", message: "Credenciales incorrectas" });
        return acceso;
      }),
    perfil: protegido.query(({ ctx }) => ctx.usuario)
  }),

  categorias: t.router({
    todas: publico.query(({ ctx }) => ctx.repo.categorias())
  }),

  proveedores: t.router({
    todos: publico.query(({ ctx }) => ctx.repo.proveedores())
  }),

  productos: t.router({
    // A. Todos los registros
    todos: publico.query(({ ctx }) => ctx.repo.productos()),
    uno: publico.input(z.object({ ProductID: id })).query(async ({ input, ctx }) =>
      ctx.repo.productoPorId(input.ProductID)),

    // B. Proyección de campos elegidos por el cliente
    campos: publico.input(z.object({ campos: z.array(campoProducto).min(1) }))
      .query(async ({ input, ctx }) => (await ctx.repo.productos()).map((producto) => {
        const seleccionado: Record<string, string | number> = {};
        for (const campo of input.campos) seleccionado[campo] = producto[campo];
        return seleccionado;
      })),

    // C. Filtros
    filtrar: publico.input(z.object({
      categoriaId: id.optional(),
      proveedorId: id.optional(),
      nombre: z.string().trim().optional(),
      precioMinimo: z.number().nonnegative().optional(),
      precioMaximo: z.number().nonnegative().optional()
    }).refine((v) => v.precioMinimo === undefined || v.precioMaximo === undefined ||
      v.precioMinimo <= v.precioMaximo, { message: "precioMinimo debe ser <= precioMaximo" }))
      .query(async ({ ctx, input }) => (await ctx.repo.productos()).filter((p) =>
        (input.categoriaId === undefined || p.CategoryID === input.categoriaId) &&
        (input.proveedorId === undefined || p.SupplierID === input.proveedorId) &&
        (input.nombre === undefined || p.ProductName.toLowerCase().includes(input.nombre.toLowerCase())) &&
        (input.precioMinimo === undefined || p.UnitPrice >= input.precioMinimo) &&
        (input.precioMaximo === undefined || p.UnitPrice <= input.precioMaximo)
      )),

    // D. JOIN entre productos, categorías y proveedores
    relaciones: publico.query(async ({ ctx }) => {
      const [productos, categorias, proveedores] = await Promise.all([
        ctx.repo.productos(), ctx.repo.categorias(), ctx.repo.proveedores()
      ]);
      const porCategoria = new Map(categorias.map((c) => [c.CategoryID, c]));
      const porProveedor = new Map(proveedores.map((p) => [p.SupplierID, p]));
      return productos.map((p) => ({
        ...p, Categoria: porCategoria.get(p.CategoryID) ?? null,
        Proveedor: porProveedor.get(p.SupplierID) ?? null
      }));
    }),

    // D. Agregación: conteo de productos y precio promedio por categoría
    agregacion: publico.query(async ({ ctx }) => {
      const [productos, categorias] = await Promise.all([ctx.repo.productos(), ctx.repo.categorias()]);
      return categorias.map((categoria) => {
        const lista = productos.filter((p) => p.CategoryID === categoria.CategoryID);
        const suma = lista.reduce((acum, p) => acum + p.UnitPrice, 0);
        return {
          CategoryID: categoria.CategoryID,
          CategoryName: categoria.CategoryName,
          totalProductos: lista.length,
          precioPromedio: lista.length ? Math.round((suma / lista.length) * 100) / 100 : 0
        };
      });
    }),

    // F. Paginación y ordenamiento
    paginar: publico.input(z.object({
      pagina: z.number().int().positive().default(1),
      limite: z.number().int().min(1).max(100).default(5),
      ordenarPor: campoProducto.default("ProductID"),
      direccion: z.enum(["asc", "desc"]).default("asc")
    })).query(async ({ ctx, input }) => {
      const registros = await ctx.repo.productos();
      const ordenados = [...registros].sort((a, b) => {
        const comparacion = typeof a[input.ordenarPor] === "string"
          ? String(a[input.ordenarPor]).localeCompare(String(b[input.ordenarPor]))
          : Number(a[input.ordenarPor]) - Number(b[input.ordenarPor]);
        return input.direccion === "asc" ? comparacion : -comparacion;
      });
      const inicio = (input.pagina - 1) * input.limite;
      return {
        pagina: input.pagina, limite: input.limite, total: registros.length,
        totalPaginas: Math.ceil(registros.length / input.limite),
        resultados: ordenados.slice(inicio, inicio + input.limite)
      };
    }),

    // E + G. CRUD protegido por JWT
    crear: protegido.input(datosProducto).mutation(async ({ ctx, input }) => {
      await validarRelaciones(ctx.repo, input);
      try { return await ctx.repo.insertar(input); } catch (error) { return traducirError(error); }
    }),
    actualizar: protegido.input(z.object({ ProductID: id, cambios: cambiosProducto }))
      .mutation(async ({ ctx, input }) => {
        const original = await ctx.repo.productoPorId(input.ProductID);
        if (!original) throw new TRPCError({ code: "NOT_FOUND", message: "Producto no encontrado" });
        await validarRelaciones(ctx.repo, { ...original, ...input.cambios });
        const actualizado = await ctx.repo.modificar(input.ProductID, input.cambios);
        if (!actualizado) throw new TRPCError({ code: "NOT_FOUND" });
        return actualizado;
      }),
    eliminar: protegido.input(z.object({ ProductID: id })).mutation(async ({ ctx, input }) => {
      const eliminado = await ctx.repo.eliminar(input.ProductID);
      if (!eliminado) throw new TRPCError({ code: "NOT_FOUND", message: "Producto no encontrado" });
      return eliminado;
    })
  })
});

export type AppRouter = typeof appRouter;

import "dotenv/config";
import { createHTTPServer } from "@trpc/server/adapters/standalone";
import { appRouter } from "./router.js";
import { construirContexto } from "./context.js";
import { RepositorioMemoria } from "../repositories/memoria.js";
import { RepositorioMongo, conectarMongo } from "../repositories/mongo.js";
import type { Repositorio } from "../types.js";

async function iniciar(): Promise<void> {
  const modo = (process.env.DB_MODE ?? "memory").toLowerCase();
  let repo: Repositorio;
  if (modo === "mongo") {
    await conectarMongo();
    repo = new RepositorioMongo();
  } else if (modo === "memory") {
    repo = new RepositorioMemoria();
  } else {
    throw new Error("DB_MODE debe ser memory o mongo");
  }

  const puerto = Number(process.env.PORT ?? 4317);
  if (!Number.isInteger(puerto) || puerto < 1 || puerto > 65535) throw new Error("PORT inválido");
  const servidor = createHTTPServer({ router: appRouter, createContext: construirContexto(repo) });
  servidor.on("error", (error: NodeJS.ErrnoException) => {
    if (error.code === "EADDRINUSE") {
      console.error(`Puerto ${puerto} ocupado. Cambia PORT en .env y reinicia.`);
    } else {
      console.error(error);
    }
    process.exitCode = 1;
  });
  servidor.listen(puerto, "127.0.0.1", () => {
    console.log(`Servidor tRPC listo | modo=${modo} | http://127.0.0.1:${puerto}`);
    console.log(`Prueba: http://127.0.0.1:${puerto}/productos.todos`);
  });
}

iniciar().catch((error: unknown) => {
  console.error("No se pudo iniciar el servidor:", error);
  process.exitCode = 1;
});

import "dotenv/config";
import assert from "node:assert/strict";
import { randomInt } from "node:crypto";
import { createTRPCClient, httpBatchLink } from "@trpc/client";
import type { AppRouter } from "../server/router.js";
import type { NuevoProducto } from "../types.js";

const puerto = Number(process.env.PORT ?? 4317);
let token = "";
const cliente = createTRPCClient<AppRouter>({
  links: [httpBatchLink({
    url: `http://127.0.0.1:${puerto}`,
    headers: () => token ? { authorization: `Bearer ${token}` } : {}
  })]
});

function paso(etiqueta: string, descripcion: string, resultado: unknown): void {
  console.log(`\n========== ${etiqueta}: ${descripcion} ==========`);
  console.log(JSON.stringify(resultado, null, 2));
}

async function probar(): Promise<void> {
  // Datos base compartidos con la práctica de GraphQL de Semana 9.
  const [categorias, proveedores, todos] = await Promise.all([
    cliente.categorias.todas.query(),
    cliente.proveedores.todos.query(),
    cliente.productos.todos.query()
  ]);
  assert.ok(categorias.length >= 8, "Deben existir al menos ocho categorías");
  assert.ok(proveedores.length >= 29, "Deben existir al menos 29 proveedores");
  assert.ok(todos.length >= 77, "Deben existir al menos 77 productos");
  paso("A", "CONSULTAR TODOS", { total: todos.length, primeros: todos.slice(0, 3) });

  const campos = await cliente.productos.campos.query({
    campos: ["ProductID", "ProductName", "UnitPrice"]
  });
  assert.equal(campos.length, todos.length);
  assert.deepEqual(Object.keys(campos[0]).sort(), ["ProductID", "ProductName", "UnitPrice"].sort());
  paso("B", "SELECCIONAR CAMPOS", { total: campos.length, primeros: campos.slice(0, 3) });

  const filtrados = await cliente.productos.filtrar.query({ categoriaId: 1, precioMinimo: 15 });
  assert.ok(filtrados.length > 0);
  assert.ok(filtrados.every((p) => p.CategoryID === 1 && p.UnitPrice >= 15));
  paso("C", "FILTROS", { total: filtrados.length, primeros: filtrados.slice(0, 3) });

  const relaciones = await cliente.productos.relaciones.query();
  assert.equal(relaciones.length, todos.length);
  assert.ok(relaciones.every((p) => p.Categoria && p.Proveedor));
  paso("D1", "JOIN PRODUCTOS + CATEGORIAS + PROVEEDORES", relaciones.slice(0, 2));

  const resumen = await cliente.productos.agregacion.query();
  assert.equal(resumen.length, categorias.length);
  assert.equal(resumen.reduce((s, c) => s + c.totalProductos, 0), todos.length);
  paso("D2", "AGREGACION POR CATEGORIA", resumen);

  const pagina = await cliente.productos.paginar.query({
    pagina: 1, limite: 5, ordenarPor: "UnitPrice", direccion: "desc"
  });
  assert.equal(pagina.total, todos.length);
  assert.equal(pagina.resultados.length, 5);
  assert.ok(pagina.resultados.every((p, i, a) => i === 0 || a[i - 1].UnitPrice >= p.UnitPrice));
  paso("F", "PAGINACION Y ORDENAMIENTO", pagina);

  const producto: NuevoProducto = {
    ProductID: 900000000 + randomInt(10000000),
    ProductName: "Producto examen tRPC",
    CategoryID: 1,
    SupplierID: 1,
    QuantityPerUnit: "1 caja",
    UnitPrice: 45.5,
    UnitsInStock: 12,
    ReorderLevel: 3
  };

  // Debe rechazar mutaciones no autenticadas.
  let rechazo = false;
  try {
    await cliente.productos.crear.mutate(producto);
  } catch (error) {
    rechazo = (error as { data?: { code?: string } }).data?.code === "UNAUTHORIZED";
    if (!rechazo) throw error;
  }
  assert.ok(rechazo, "Se esperaba rechazo UNAUTHORIZED sin JWT");
  paso("G1", "ACCESO SIN JWT BLOQUEADO", { resultado: "UNAUTHORIZED (esperado)" });

  const email = process.env.DEMO_EMAIL;
  const password = process.env.DEMO_PASSWORD_CLIENT;
  if (!email || !password) throw new Error("Faltan DEMO_EMAIL o DEMO_PASSWORD_CLIENT: ejecuta npm run setup");
  const acceso = await cliente.auth.login.mutate({ email, password });
  token = acceso.token;
  const perfil = await cliente.auth.perfil.query();
  assert.equal(perfil.email, email);
  paso("G2", "LOGIN JWT Y ACCESO PROTEGIDO", { perfil, tokenGenerado: Boolean(token) });

  // CRUD con recuperación tras error para no dejar datos de pruebas.
  let creado = false;
  try {
    const nuevo = await cliente.productos.crear.mutate(producto);
    creado = true;
    assert.equal(nuevo.ProductID, producto.ProductID);
    paso("E1", "INSERTAR", nuevo);

    const editado = await cliente.productos.actualizar.mutate({
      ProductID: producto.ProductID,
      cambios: { ProductName: "Producto tRPC actualizado", UnitPrice: 59.9 }
    });
    assert.equal(editado.ProductName, "Producto tRPC actualizado");
    assert.equal(editado.UnitPrice, 59.9);
    paso("E2", "MODIFICAR", editado);

    const borrado = await cliente.productos.eliminar.mutate({ ProductID: producto.ProductID });
    creado = false;
    assert.equal(borrado.ProductID, producto.ProductID);
    const despues = await cliente.productos.uno.query({ ProductID: producto.ProductID });
    assert.equal(despues, null);
    paso("E3", "ELIMINAR", { eliminado: borrado, verificacion: despues });
  } finally {
    if (creado) await cliente.productos.eliminar.mutate({ ProductID: producto.ProductID });
  }

  console.log("\nTODAS LAS PRUEBAS tRPC FINALIZARON CORRECTAMENTE.");
}

probar().catch((error: unknown) => {
  console.error("\nFALLO EN LAS PRUEBAS:", error);
  process.exitCode = 1;
});
